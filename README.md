# Compass Voice Interview

Voice mock Oxbridge interviews: a tutor asks a question, then pushes back on the student's reasoning.
Live at https://compass-voice-interview.lovable.app. Built with [Lovable](https://lovable.dev); pushes to `main` sync back to it.

```sh
bun install
bun run dev        # local app
bunx vitest run    # tests (CI also runs tsc, eslint, evals --dry-run and build)
```

Rules for agents and contributors: `AGENTS.md`. Workflow skills: `.claude/skills/`. Old plans: `docs/archive/`.
